# Energy Storage Vocabulary

## 储能术语Skill

用日常语言描述储能设备、状态、指标或运行方式，找到合适的术语，分清相近概念，并获得有来源的准确表达。

这是一个面向储能产品、设计和业务沟通的反向术语词典。它帮助你从“我想表达什么”找到“这个概念叫什么”，也帮助你避免把相近但不同的词混在一起。

## 能做什么

- 从口语描述定位术语，例如“电池还有百分之多少的电”对应 **SOC／电池荷电状态**。
- 区分相近概念，例如 **备电模式**（预先设定的策略）和 **孤岛运行**（停电后的实际状态）。
- 把模糊描述改写成更准确的需求或 UI 文案。
- 说明统计口径、适用场景和不确定性，并提供网站条目或外部依据。
- 在没有可靠匹配时明确说明未覆盖或信息不足，不强行编造术语。

当前覆盖户用储能、工商业储能、大型储能和光储充，共 35 条网站正式条目。

## 使用

在 Codex 中直接描述问题：

```text
$energy-storage-vocabulary 经常停电的地区应该设计什么工作模式？
```

项目内安装时，将本仓库放在：

```text
.agents/skills/energy-storage-vocabulary/
```

然后使用 `$energy-storage-vocabulary` 调用。

## 内容边界

网站目录决定首批覆盖范围，但网站发布或个人审核记录不等于专业认证。网站内容与可靠依据冲突时，Skill 会说明差异，不自动修改网站。厂商用法和地区规则会标明适用范围。

这个 Skill 用于术语定位、概念解释和准确表达，不替代工程设计、设备选型、安装调试、安全规范、厂商文档或当地法规，也不提供具体配置值。

## 来源与维护

术语快照来自 [energy-dictionary-glossary](https://github.com/shiqiuhao/energy-dictionary-glossary) 的正式条目，并保留原条目中的参考来源。快照采用手动更新，不自动同步网站；新增或修改术语后应同时更新索引和快照。

运行结构检查：

```bash
python3 check.py
```

该检查验证条目数量、ID、版本、索引链接、站内路径、本地引用和来源 URL；它不等同于专业审查，也不替代真实问答验收。
